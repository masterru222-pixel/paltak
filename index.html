About Me

From Rookie to Veteran

I'm paltak — a self-taught developer who started coding in 2016 and never stopped. What began as curiosity about how Discord bots work turned into a decade-long passion for backend engineering, API design, and community building.

Over the years I've built 60+ Discord bots — moderation systems, music players, game stat trackers, automation tools, ticket systems, and full-scale bot platforms. My code runs on thousands of servers and serves over 100K users daily across the globe.

In 2026, I founded Dead Seller — my own Discord server where I bring together developers, creators, and gamers. I'm the owner, head admin, lead developer, and head moderator all in one. Every bot, every channel, every system — built by me.

I specialize in JavaScript/TypeScript, Node.js, Python, and the entire Discord API ecosystem. I believe in writing clean, type-safe, scalable code and building tools that make online communities genuinely better.

On the systems level, I'm deeply into modern C++ (C++20/23) — lock-free concurrency, custom networking stacks with Boost.Asio, gRPC microservices, and high-performance game server engines. I've built real-time systems that handle 10K+ concurrent connections with deterministic latency, and I write cross-platform C++ using CMake with exhaustive CI/CD pipelines. My low-level work includes memory-mapped I/O, SIMD optimizations, and custom allocators — because sometimes you need that extra 5% perf.

I'm also experienced in C# and the .NET ecosystem — building everything from Windows desktop applications with WPF to cross-platform services running on .NET. My C# work spans Discord bot development, game server tooling, and high-throughput REST APIs.

On the security side, I've spent years doing reverse engineering — tearing apart binaries with IDA Pro, Ghidra, x64dbg, and dnSpy. I reverse Windows PE files, Linux ELFs, and game memory structures. I've written loaders, injectors, and custom unpackers. I understand PE/ELF headers, import tables, section manipulation, and anti-debugging techniques inside out. My low-level knowledge extends to kernel-mode research, syscall hooking, and analysis of obfuscated malware samples.

I've built and tested network stress tools for security research — layer 7 HTTP flooders, SYN flooders, UDP amplification, and custom protocol fuzzers. These are strictly for authorized penetration testing and security education. Understanding how DDoS attacks work is essential for building systems that withstand them. I've helped multiple small services harden their infrastructure against common attack vectors.

Beyond coding, I mentor new developers, contribute to open-source, and I'm always working on something new. The journey from writing my first !ping command to where I am today has been incredible — and it's far from over.

My Journey

The Timeline

From writing my first line of code to owning a community — here's the full story.

2016 — The Beginning

First Steps Into Code

Wrote my first line of JavaScript. Built a basic moderation bot that could kick, ban, and purge — it crashed every hour but it worked. I was instantly hooked. Joined my first developer Discord server and realized how much I didn't know.

2017 — Growing Pains

Learning the Ropes

Discovered async/await, event emitters, and why you never put your bot token in source code. Rewrote my bot 3 times from scratch. Built my first command handler. Started contributing to open-source Discord libraries.

2018 — First Public Bot

Launch of Project Nexus

Released my first public bot — a moderation + utility bot that reached 500 servers in the first month. Learned about sharding, rate limits, and the pain of MySQL migrations at 3 AM. Made my first $50 from donations.

2019 — Going Pro

Freelance & Open Source

Started taking commissions for custom Discord bots. Released my first open-source library on GitHub. Contributed to the discord.js docs. Wrote over 10K lines of production code. Built my first music bot using Lavalink.

2020 — Full Stack

Beyond the Bot

Built a web dashboard for my bots using React. Learned TypeScript, Docker, and CI/CD pipelines. My biggest bot hit 10K servers. Started exploring alternative platforms and opened up to full-stack development. Also began dabbling in C++ — wrote a simple Discord bot using the Sleepy Discord library just to understand how the Gateway API works at the packet level.

2021 — Slash Commands

Adapting to Change

When Discord deprecated message content, I migrated all bots to slash commands. Rewrote command handlers, permission systems, and docs from scratch. Published a migration guide that helped 5K+ developers transition.

2022 — At Scale

Building for Thousands

Refactored my main bot into a microservice architecture with Redis caching, PostgreSQL sharding, and Kubernetes. Achieved 99.9% uptime across 25K+ servers. Built a real-time analytics dashboard for server insights.

2023 — Burnout

Taking a Step Back

After years of non-stop development, I hit burnout. Took 3 months off, traveled, played games, and rediscovered why I love coding. Came back with cleaner code, better patterns, and fresh ideas.

2024 — Modern Stack

Next Generation Tools

Returned with a fully modernized tech stack — ESM-only TypeScript, edge functions, real-time WebSocket analytics, and a focus on DX. Launched a no-code bot builder platform for non-technical users. Deepened my C# and .NET skills, building WPF tooling and ASP.NET backends. Started taking reverse engineering seriously — binary analysis, IDA Pro scripting, and CTF reversing challenges.

2025 — Building Home

Creating Dead Seller

Started planning my own Discord server. Designed the channel structure, built custom moderation bots, and laid the foundation for what would become Dead Seller — a community for devs, creators, and gamers. On the C++ side, I built Velox Engine — a high-performance game server framework using C++20, Boost.Asio, and lock-free queues — which I now use for internal tooling and real-time data pipelines.

2026 — Present Day

Owner & Developer

I'm the proud owner of Dead Seller — a growing community of 20 members. I code daily, mentor new developers, run my server, reverse engineer binaries for fun, and build security research tooling. C#, C++, RE, and DDoS mitigation — the journey continues.
